# CS5800 HW7 Creational Design Patterns

This project implements the two parts of HW7:

- Builder pattern for Pizza Hut, Little Caesars, and Dominos pizzas
- Factory, Abstract Factory, and Singleton patterns for randomized macronutrient meals

## Source packages

- `src/hw7/builder` - pizza model, builder, and `PizzaDriver`
- `src/hw7/macronutrient` - diet plans, food categories, singleton factories, abstract factory, and `MealDriver`

## Run in IntelliJ IDEA

Open the project, mark `src` as the Sources Root if necessary, and run:

- `hw7.builder.PizzaDriver`
- `hw7.macronutrient.MealDriver`

Both drivers were compiled and executed successfully with Java 21.
